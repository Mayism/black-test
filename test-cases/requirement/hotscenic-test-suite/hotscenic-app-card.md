## UI 元素匹配优先级

1. 用户可见中文文本（如【热门景点】、【更多】、【语音讲解】、【导航】、【景点列表】）
2. 图标含义或区域位置（如返回按钮、景点卡片、缩略图）
3. 可访问性文本 / Key（仅在可见文本缺失时使用）

## 导航约定

- **返回上一级**: 使用页面标题栏左侧的返回按钮或系统返回键
- **页面跳转**: 点击热门景点卡片或景点列表条目后等待详情页标题和核心内容出现
- **跨应用跳转**: 点击【导航】按钮后验证地图应用界面已弹出或加载
- **模块内浏览**: 热门景点模块支持横向滑动，但无 fixture 时只验证当前可见卡片结构
