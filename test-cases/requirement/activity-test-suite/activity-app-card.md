# 活动模块 应用卡片

## 应用信息

- **bundleName**: `com.example.matchmaking`（模板占位，正式版本需替换为实际 bundleName）
- **应用类型**: 社交相亲元服务
- **启动后默认页面**: 首页 — 【推荐】Tab

## 页面结构

### 首页顶部Tab栏

| Tab | 说明 |
|------|------|
| **推荐** (默认) | 推荐内容列表，含筛选图标入口 |
| **活动** | 活动列表页，城市选择器 + 未来活动 + 往期活动 |

### 页面导航

| 页面 | 入口 | 说明 |
|------|------|------|
| 活动列表页 | 首页顶部点击【活动】Tab | 城市选择、活动卡片列表、往期活动分区 |
| 活动详情页 | 活动列表页点击活动卡片 | 主图封面、信息卡片、Swiper轮播、底部报名按钮 |
| 城市选择器 | 活动列表页点击城市名称/下拉箭头 | 城市列表弹窗或新页面 |
| 我的页 | 底部标签或导航入口（根据实际结构） | 用户信息、我的订单入口等 |
| 我的订单页 | 我的页点击【我的订单】入口 | 已报名活动列表及状态标签 |

## UI 元素匹配优先级

**中文 label > 英文 label > Key**

所有操作均以用户可见的中文文本为准进行匹配。

## 导航约定

- **返回上一级**：顶部左上角返回箭头（标准 ArkUI BackButton）。
- **Tab切换**：点击顶部Tab栏文字切换。
- **页面跳转**：点击对应卡片/按钮，标准页面过渡动画。

## 测试数据与 fixture 边界

- 当前使用 mock 数据（rawfile JSON），活动信息、城市列表、订单数据均为固定 mock 值。
- 活动模块的 mock 数据可能包含：多个城市的活动、不同状态的活动（可报名/已报满/已结束）、已报名订单记录。
- 若 mock 数据中缺少特定状态活动（如无已报满活动），依赖该数据的用例应通过 `complete(success=false)` 明确报告。
- 报名流程（P1）一期仅展示提示，不涉及真实支付或后端交互。

## 权限弹窗

本活动模块不涉及特殊权限弹窗（无定位、日历、通知等权限需求）。

## 已知的慢操作

| 操作 | 等待时间 | 说明 |
|------|---------|------|
| 城市切换后列表刷新 | ≥1 秒 | 等待活动列表重新请求/加载 |
| 活动列表首次加载 | ≥1 秒 | 等待 mock 数据加载和列表渲染 |
| 活动详情页加载 | ≥1 秒 | 等待详情数据加载和Swiper初始化 |
| Swiper图片自动轮播 | ≥2 秒 | 等待自动轮播效果触发 |
