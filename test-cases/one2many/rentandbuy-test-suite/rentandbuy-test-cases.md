## 评判口径

一多适配通过同时需要报告结果和截图证据：

- **布局命中**：列数、分栏、导航位置、弹窗形态符合 PRD 和目标 `widthBp`
- **内容可读**：标题、价格、按钮、列表项、表单字段完整可见
- **交互可达**：关键按钮不被遮挡，弹窗内容不超屏
- **视觉稳定**：无横向溢出、元素重叠、关键文字截断、图片比例失真
- **断点差异**：`sm/md/lg` 目标断点体现不同布局策略，而非同一布局等比例缩放
