# 旅游景区服务 应用卡片

## 应用信息

- **bundleName**: `com.example.scenic`
- **主 Ability**: `EntryAbility`
- **启动后默认页面**: 首页（HomePage）

## 页面结构（TabBar + 多级页面导航）

### TabBar 一级页面

| 序号 | 页面类名 | Tab 文本 | 说明 |
|------|---------|----------|------|
| 1 | `HomePage` | 首页 | 轮播图、公告入口区域、服务导航入口、热门景点推荐、攻略游记 |
| 2 | `TicketPage` | 门票 | 门票分类列表，每项为可点击的门票卡片 |
| 3 | `GuidePage` | 导览 | 景区地图展示，地图上标注景点位置标记点 |
| 4 | `MinePage` | 我的 | 账号关联、订单管理、旅客管理、地址管理 |

### 二级/三级页面

| 层级 | 页面类名 | 入口 | 说明 |
|------|---------|------|------|
| L2 | `AnnouncementListPage` | 首页 → 点击公告区域 | 公告列表，每条显示标题和发布日期 |
| L2 | `AnnouncementDetailPage` | 公告列表 → 点击公告条目 | 图片、公告标题、发布时间、公告内容 |
| L2 | `TicketDetailPage` | 门票 → 点击门票卡片 | 门票名称、价格、有效期、预订须知 |
| L2 | `SpotDetailPage` | 导览 → 点击景点标记 → 查看详情 | 景点名称、详细介绍、图片、语音讲解按钮 |
| L2 | `TicketBookingFormPage` | 门票详情 → 立即预订 | 日期选择器、数量选择器、**预订人信息（姓名+电话+身份证号）**、确认预订按钮 |
| L3 | `BookingConfirmPage` | 预订表单 → 确认预订 | 预订摘要（名称/日期/数量/旅客信息/金额）、立即支付按钮 |

## 可观察结果位置

本应用为常规业务元服务，**不设专门的结果面板**。checkpoint 验证应通过以下方式：

- **页面跳转**：观察页面标题栏文字、页面主体内容区域是否变化
- **文本内容**：页面中可见的文本元素（门票名称、价格、公告标题、旅客姓名/电话等）
- **按钮状态**：按钮文字/图标变化（如播放→暂停图标切换）、按钮是否可点击
- **列表展示**：页面中列表项的数量和基本内容
- **表单输入**：输入框中的文本值是否为预期内容、格式是否合规
- **组件交互**：日期选择器弹出、信息卡片弹出、键盘升起/收起等视觉变化

## UI 元素命名约定

| 类型 | 示例 |
|------|------|
| 按钮文本 | `立即预订`、`查看详情`、`语音讲解`、`确认预订`、`立即支付` |
| 标签/标题 | `景区公告`、`门票`、`导览`、`预订须知` |
| 输入框标签 | `预订人姓名`、`联系电话`、`身份证号` |
| 日期选择器 | DatePicker（滑动选择年月日） |
| 数量选择器 | `-` `+` 按钮或数字输入框 |
| 地图标记 | 景点标记点（可点击的 map marker） |

UI 元素匹配优先级：**中文 label > 语义定位（如页面标题区、底部 TabBar）**。

## 导航约定

- **切换 Tab**：点击底部 TabBar 中的对应 Tab 按钮（首页 / 门票 / 导览 / 我的）
- **进入详情**：点击列表中的卡片 / 条目
- **返回上一级**：顶部左上角返回箭头（标准 ArkUI BackButton）或系统返回手势
- **页面跳转**：使用标准路由动画

## 权限弹窗

本应用需要以下权限，首次触发相应功能时会弹出授权对话框：

| 权限 | 触发场景 | 处理方式 |
|------|---------|----------|
| LOCATION | 进入导览 Tab 加载地图 | 弹出后默认点"允许" |
| APPROXIMATELY_LOCATION | 进入导览 Tab 加载地图 | 弹出后默认点"允许" |

## 已知的慢操作（需要显式等待）

- **地图渲染**：进入导览 Tab 后等待 ≥2 秒再验证地图和标记点
- **语音播报加载**：点击语音讲解后等待 ≥2 秒再验证播放状态
- **网络请求**：首页公告、门票列表、景点信息等网络数据加载，每个步骤后等待 1~2 秒
