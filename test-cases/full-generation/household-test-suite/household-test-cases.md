## 详情

### MUST-01 首页基础结构展示

- **等级**: L0
- **前置条件**: 应用已启动并停留在【首页】；网络连接正常
- **步骤**:
  1. 确认当前页面底部标签栏状态 → 底部三个标签【首页】、【全部服务】、【我的】均可见，【首页】标签处于高亮选中状态
  2. 查看首页顶部导航栏区域 → 顶部左侧显示当前城市名称，右侧显示搜索框入口
  3. 查看首页中间内容区域 → 搜索框下方可见常用分类快捷入口（如【日常清洁】、【家电维修】等）；下方【精选服务】区域可见至少1张服务卡片，卡片包含图片、标题和价格或按钮
- **预期结果**: 首页完整展示底部三个标签导航、顶部城市与搜索框、中间常用分类入口和精选服务卡片区域

### MUST-02 搜索服务并查看搜索结果

- **等级**: L0
- **前置条件**: 应用已启动并停留在【首页】；网络连接正常
- **步骤**:
  1. 点击顶部【搜索框】 → 进入搜索页面，搜索框获取焦点，输入法键盘弹出
  2. 在搜索框中输入"保洁" → 搜索框中显示已输入的文字"保洁"
  3. 点击键盘上的【搜索】按钮提交搜索 → 输入法收起，页面显示搜索结果列表，列表条目标题显示包含"保洁"关键词的服务；如无匹配结果则显示空状态提示
- **预期结果**: 搜索结果页面成功展示包含"保洁"关键词的服务列表，或显示无结果空状态提示

---

### MUST-03 从首页查看服务详情页

- **等级**: L0
- **前置条件**: 应用已启动并停留在【首页】；网络连接正常
- **步骤**:
  1. 在首页【精选服务】区域，点击一张可见的服务卡片 → 页面跳转到服务详情页，顶部显示返回按钮和服务标题名称
  2. 查看服务详情页主体内容区域 → 详情页展示服务主图和价格信息（价格数字或【咨询报价】文本），以及服务内容或服务流程等介绍区域
  3. 查看页面底部操作区域 → 页面底部可见【立即预约】或【咨询报价】主操作按钮
- **预期结果**: 服务详情页加载完成：顶部有返回按钮和服务标题；页面包含服务主图、价格或咨询报价信息、服务内容介绍；底部显示【立即预约】或【咨询报价】按钮

### SHOULD-01 切换城市后首页城市名称更新

- **等级**: L1
- **前置条件**: 应用已启动并停留在【首页】；网络连接正常
- **步骤**:
  1. 点击首页顶部左侧的城市名称 → 进入城市选择页，显示可选择的城市列表
  2. 在城市列表中点击一个与当前城市不同的城市名称 → 页面返回首页，顶部城市名称更新为所选城市名称
- **预期结果**: 首页顶部显示的城市名称已变更为所选城市，页面核心区域正常展示

---

### SHOULD-02 全部服务页面分类导航切换

- **等级**: L1
- **前置条件**: 应用已启动并停留在【首页】；网络连接正常
- **步骤**:
  1. 点击底部标签【全部服务】 → 页面切换到【全部服务】tab，【全部服务】标签高亮选中；左侧显示服务分类列表，右侧显示服务卡片列表
  2. 在左侧分类列表中点击一个分类名称（如【日常清洁】） → 右侧服务卡片列表内容更新为所选分类下的服务；左侧被点击的分类处于高亮选中状态
- **预期结果**: 【全部服务】页分类导航正常：点击左侧分类后右侧服务列表内容随之切换，左侧对应分类高亮

---

### SHOULD-03 未关联账号-点击我的订单引导账号关联

- **等级**: L1
- **前置条件**: 应用已启动并停留在【首页】；网络连接正常
- **步骤**:
  1. 点击底部标签【我的】 → 页面切换到【我的】页；用户信息卡右侧显示【关联账户】按钮，确认账号处于未关联状态
  2. 点击【我的订单】入口 → 页面弹出账号关联引导弹窗或跳转到关联引导页面，未直接进入订单列表页面
- **预期结果**: 未关联账号状态下点击【我的订单】触发账号关联引导，展示关联引导弹窗或关联引导页面，订单列表页面未直接打开

## 需要 Fixture / 不适合黑盒自动化的场景

以下场景已按可执行性分级排除在 JSON 用例之外，如需覆盖，必须先配置对应 fixture 或测试环境：

### B 级 — 需要 fixture

| 场景 | 所需 fixture | 说明 |
|------|-------------|------|
| 预约下单完整流程 | 已关联账号 + 已有默认地址 + 可预约服务（确定服务名） | 账号关联可写入用例但不能跨 case 保持；下单页进入需已关联 + 已选服务 |
| 下单校验-地址为空 | 已关联账号 + 进入下单页 | 进入下单页需要账号关联 + 已选可预约服务（需已知服务名） |
| 下单校验-未选上门时间 | 已关联账号 + 进入下单页 | 同上 |
| 下单校验-未选服务规格 | 已关联账号 + 进入下单页 | 同上 |
| 下单校验-备注超100字 | 已关联账号 + 进入下单页 | 同上 |
| 待支付订单-取消/立即支付 | 预置待支付订单 + mock 支付环境 | 需后台造数 |
| 待使用订单-订阅通知/添加日程/申请退款 | 预置待使用订单 | 需后台造数 |
| 已完成订单-申请退款/联系客服 | 预置已完成订单 | 需后台造数 |
| 地址管理-新增/编辑/删除 | 已关联账号 + 已有地址数据 | 账号关联不能跨 case 保持 |
| 咨询报价-拨号面板 | 咨询类服务数据 + 确定服务名 | PRD 未指定哪些服务为咨询类型，无法确定入口 |
| 搜索无结果空状态 | mock 数据设为空 | 正常环境有数据 |
| 订单列表为空 | mock 数据设为空 | 正常环境有数据 |

### C 级 — 不适合黑盒自动化

| 场景 | 原因 |
|------|------|
| 真实支付成功 | 依赖真实支付商户参数 |
| 真实退款到账 | 依赖后端退款流程 |
| 真实 Push 通知送达 | 依赖 PushKit 和网络环境 |
| 真实日历写入后跨系统校验 | 跨 app 校验不可控 |
| 支付超时自动取消 | 需等待真实倒计时，时间不可控 |
