# 旅游景区服务应用 - 产品需求文档

---

## 1. 产品概述

### 1.1 产品定位

面向景区旅游场景的HarmonyOS元服务应用模板，为景区管理方和游客提供一站式智慧旅游服务。集成华为账号、通话、地图、音频等生态服务，支持直接定制或挑选组件使用。

### 1.2 目标用户

| 用户类型 | 需求 |
|----------|------|
| **游客** | 获取景区信息、预订门票、查找设施、分享游记 |

### 1.3 核心价值

- 提供完整的景区旅游服务闭环
- 组件化设计，支持灵活选用和定制
- 深度集成华为生态服务

## 2. 业务场景

### 2.1 游客出行流程

| 行前准备 | 到达景区 | 景区游览 | 返程回顾 |
|----------|----------|----------|----------|
| 查看公告 | 门票预订 | 景点导览 | 订单查看 |
| 浏览攻略 | 关联服务 | 语音播报 | 游记分享 |
| 规划线路 | 查找餐饮 | 实时实况 | 评价反馈 |
| 预订住宿 | 拨打热线 | 周边配套 | 再次出行 |

### 2.2 核心场景

| 场景 | 描述 | 用户痛点 |
|------|------|----------|
| 景区信息获取 | 行前/行中了解景点、公告、实况 | 信息分散 |
| 门票预订 | 在线预订门票 | 需多平台切换 |
| 景区导览 | 景区内导航、查找设施 | 方向感差 |
| 语音讲解 | 景点语音介绍 | 租赁设备麻烦 |
| 餐饮住宿 | 周边餐饮住宿查找 | 信息不透明 |
| 游客管理 | 多人出行旅客信息管理 | 重复填写 |
| 游记分享 | 分享游览体验 | 缺乏专业平台 |

## 3. 功能模块

### 3.1 首页（Home）

| 功能 | 说明 |
|------|------|
| 轮播展示 | 景区宣传图片自动轮播 |
| 公告信息 | 展示最新公告及详情 |
| 服务导航 | 文旅商城、票务预订、餐饮住宿、游览线路 |
| 热门景点 | 推荐景点列表及详情 |
| 攻略游记 | 游记浏览、搜索、详情 |

### 3.2 门票（Ticket）

| 功能 | 说明 |
|------|------|
| 门票列表 | 展示可预订门票分类 |
| 门票详情 | 价格、说明、预订须知 |
| 门票预订 | 选择日期、数量、旅客 |
| 订单支付 | 支付、取消订单 |

### 3.3 导览（Guide）

| 功能 | 说明 |
|------|------|
| 景点导览 | 地图展示景点位置，支持导航 |
| 周边设施 | 餐饮、住宿、卫生间位置 |
| 语音播报 | 景点语音介绍播放 |
| 景点实况 | 人流、排队、开放状态 |

### 3.4 我的（Mine）

| 功能 | 说明 |
|------|------|
| 账号关联 | 华为账号/手机号关联 |
| 订单管理 | 购物订单、门票订单 |
| 旅客管理 | 常用旅客增删改 |
| 地址管理 | 收货地址管理 |

## 5. 技术与交互

### 5.1 技术约束

| 环境项 | 要求 |
|--------|------|
| IDE | DevEco Studio 5.0.3+ |
| SDK | HarmonyOS 5.0.3+ |
| 设备 | 华为手机/折叠屏 |
| 系统 | HarmonyOS 5.0.3(15)+ |

**必需权限**：INTERNET、APPROXIMATELY_LOCATION、LOCATION

### 5.2 交互流程

**门票预订流程**：选择门票 → 填写日期/数量 → 选择旅客 → 确认订单 → 完成支付

**景区导览流程**：查看地图 → 选择景点 → 查看详情/导航 → 语音播报

**账号关联流程**：进入我的 → 关联账号 → 选择方式 → 授权验证 → 关联成功

### 5.3 页面导航

TabBar：首页 → 门票 → 导览 → 我的
